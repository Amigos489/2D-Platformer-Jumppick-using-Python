# 2D-Platformer Jumppick
This repository contains the source code of the game Jumppick. it is a simple 2d platformer written in **Python** using the **Pygame** library.
## Controls
character control is as simple as possible: move to the right on **arrow right**/**d**, and for move to the left **arrow left**/**a**
## Launching the game
The game is written on version **Python 3.12.7** and **Pygame 2.6.1** under **Windows**. To start playing, you need to run **main.exe**. It is also necessary that the **img** and **sound** directories are in the same directory as the game.
To change your best result, you need to change the value in the **best_record.txt** file. To view the original code, open the **main.py** file. All necessary files are in the **Jumpplick.zip** archive.
